# Shooter-Game-3D
Videojuego de disparos en tercera persona desarrollado en Unity, en el que el jugador debe defender una base de los ataques de oleadas de enemigos.

El objetivo principal es proteger la base el mayor tiempo posible, eliminando a los enemigos antes de que consigan destruirla. Para ello, el jugador tendrá que utilizar sus habilidades de combate y estrategia para sobrevivir a los ataques.

Características principales

- Entorno 3D: escenario tridimensional desarrollado en Unity.
- Sistema de combate: mecánicas de disparo y eliminación de enemigos.
- Defensa de una base: la base dispone de una cantidad limitada de vida que debe protegerse.
- Oleadas de enemigos: los enemigos atacan al jugador y a la base.
- Sistema de salud: tanto el jugador como la base pueden recibir daño.
- Supervivencia: el jugador debe resistir los ataques y evitar que la base sea destruida.
